Stako Control Panel v0.1.0

Panduan Instalasi Stako di VPS Ubuntu

Ubuntu Server 22.04 LTS & 24.04 LTS (amd64 / arm64) — dari awal hingga siap produksi.

1. Prasyarat Server

  • OS: Ubuntu Server 22.04 LTS atau 24.04 LTS (amd64 atau arm64).
  • Akses: root atau user dengan hak sudo lewat SSH.
  • Spesifikasi Minimum:
    • Basic: 1 vCPU, 1 GB RAM, 15 GB disk.
    • Standard (disarankan): 2 vCPU, 2–4 GB RAM, 25 GB disk.
    • Full: 2+ vCPU, 4+ GB RAM, 40 GB disk.
  • Port Jaringan: Buka 22/tcp (SSH), 80/tcp, 443/tcp (Web), dan 8083/tcp (Panel Stako). Opsional: 21/tcp (FTPS), 25/465/587/993 (Mail), 53/tcp+udp (jika --with-dns).

2. Persiapan Awal VPS

Masuk ke VPS via SSH, atur hostname FQDN, zona waktu, dan perbarui paket sistem:

ssh root@IP_VPS_ANDA

sudo hostnamectl set-hostname panel.domainanda.com
sudo timedatectl set-timezone Asia/Jakarta
sudo apt-get update && sudo apt-get upgrade -y

3. Metode Instalasi

Opsi A — Instalasi Otomatis dari GitHub Releases (Rekomendasi)

Installer cerdas (installer/install.sh) menjalankan apt-get update && upgrade, menambahkan repo resmi (PHP 8.4/8.5, NodeSource 22.x, Docker CE), memeriksa versi tiap paket (menghapus versi lama yang tidak kompatibel lalu memasang versi yang sesuai), memverifikasi checksum binary Stako, menerapkan hardening baseline OS, dan menyalakan layanan systemd.

# 1. Unduh skrip installer
curl -fsSLO https://raw.githubusercontent.com/StakoCP/stako/main/installer/install.sh

# 2. (Opsional) Simulasi rencana instalasi tanpa mengubah sistem
sudo bash install.sh --dry-run --preset standard

# 3. Jalankan instalasi (preset: basic | standard | full)
sudo bash install.sh --preset standard
DNS Server Opsional: Secara default PowerDNS tidak dipasang. Tambahkan --with-dns jika ingin memasang PowerDNS bawaan.

Opsi B — Instalasi dari Binary Lokal (dist/)

Jika Anda sudah melakukan cross-compile ke folder dist/ di komputer lokal:

# Dari komputer lokal: unggah dist/ dan installer ke VPS
scp -r dist installer/install.sh root@IP_VPS_ANDA:/root/stako-pkg/

# Di VPS: verifikasi checksum dan jalankan installer
cd /root/stako-pkg
sha256sum -c dist/SHA256SUMS --ignore-missing
sudo bash install.sh --preset standard --from-dir ./dist

4. Paket Backend per Preset

Preset Layanan & Dependensi
Basic nginx, PHP 8.4 (php8.4-fpm + ekstensi), mariadb-server, nftables, fail2ban, auditd, unattended-upgrades, certbot, openssh-server
Standard (default) Semua Basic + apache2, postgresql, nodejs (22.x), golang-go, python3, docker-ce + uidmap + dbus-user-session (Docker rootless), redis-server, postfix + dovecot + rspamd, proftpd-basic, restic
Full Semua Standard + php8.3-fpm, php8.5-fpm, rabbitmq-server, clamav, spamassassin, goaccess, libnginx-mod-http-modsecurity

5. Verifikasi Setelah Instalasi

# Cek status layanan systemd
sudo systemctl status stako-agent stako-core nginx --no-pager

# Jalankan diagnosa Stako
stako --insecure doctor

# Cek log instalasi & konfigurasi tersimpan
sudo tail -n 50 /var/log/stako-install.log
cat /etc/stako/install.yml

6. Login Pertama & Pengamanan Awal

Buka browser ke https://IP_VPS_ANDA:8083 dan login memakai akun admin serta password yang tampil di akhir proses stako-core bootstrap-admin.
  1. Wajib Aktifkan 2FA TOTP: Panel akan langsung meminta setup 2FA pada login pertama admin/reseller. Pindai QR code lalu simpan 8 recovery code di tempat aman.
  2. Pasang Domain & SSL: Buka menu Domains, tambahkan domain panel Anda, lalu terbitkan sertifikat Let's Encrypt.
  3. Jalankan Pemindaian Keamanan: Buka menu Security & Updates → klik Run Security & CVE Scan.

Penting: Cadangkan /etc/stako/keys/master.key di luar server. Tanpa kunci ini, arsip backup terenkripsi, secret environment aplikasi, dan secret 2FA tidak dapat didekripsi saat pemulihan.
