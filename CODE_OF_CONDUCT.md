# Contributor Covenant Code of Conduct

We are committed to providing a welcoming, respectful, and harassment-free experience for everyone participating in the **Stako** (`StakoCP/stako`) community.

- Be respectful and constructive in issues, pull requests, and discussions.
- Harassment, discrimination, or personal attacks will not be tolerated.
- Report unacceptable behavior privately to the project maintainers via GitHub.
