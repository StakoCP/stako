Tentang Stako

Panel kontrol hosting open-source berlisensi MIT yang menggabungkan performa Go, antarmuka Svelte modern, dan isolasi keamanan berlapis.

Arsitektur Dual-Process (Least Privilege)

stako-core berjalan sebagai user non-privileged untuk melayani Web UI, REST API (OpenAPI 3.1), dan SQLite WAL. Semua operasi sistem dieksekusi oleh stako-agent melalui Unix domain socket dengan allowlist perintah yang ketat.

Keamanan Bawaan

Dilengkapi autentikasi TOTP 2FA, CSRF protection, enkripsi amplop AES-256-GCM untuk kredensial, audit log berantai hash (tamper-evident), nftables firewall, Fail2ban, ModSecurity WAF, dan mode Lockdown darurat.

Ekosistem Plugin Komunitas

Komunitas dapat menambahkan modul, webhook event hook, halaman dashboard kustom, serta manifest aplikasi katalog baru tanpa perlu melakukan fork terhadap kode inti Stako.

Teknologi Inti

Backend ditulis dalam Go (single static binary), frontend menggunakan Svelte 5 + Astro yang di-embed ke dalam binary, serta mendukung penuh Ubuntu 22.04 dan 24.04 LTS (amd64 & arm64).
