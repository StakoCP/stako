Control Panel Hosting Modern, Ringan, dan Aman Berbasis Go

Kelola Nginx & Apache2, multi-PHP, MariaDB & PostgreSQL (PgBouncer + PITR), Rootless Docker, Git Preview Environments, WordPress Toolkit, Mail + SMTP Relay, dan Plugin komunitas dalam satu binary ringan.

Mulai Instalasi & Simulator Pelajari Arsitektur

Fitur Unggulan

Dirancang untuk VPS pribadi, agensi web, hingga penyedia hosting skala produksi.

Web Server & Cache CDN

Nginx, Apache2, atau hybrid Nginx+Apache2 dengan Let's Encrypt otomatis, Cloudflare real-IP & purge, Redis Object Cache satu klik, dan Nginx Microcache.

Docker & Git Preview

Rootless Docker + Compose, build dari GitHub atau path lokal, serta Preview Environment otomatis per branch/PR lengkap dengan subdomain reverse proxy.

WordPress Toolkit

Deteksi semua instalasi WordPress, update massal core/plugin/tema, staging satu klik, hardening keamanan, dan auto-login aman.

Database Lanjutan

MariaDB + phpMyAdmin dan PostgreSQL + phpPgAdmin, lengkap dengan PgBouncer connection pooler, streaming replication, dan Point-in-Time Recovery (PITR).

Mail + SMTP Relay

Postfix, Dovecot, Rspamd, DKIM/SPF/DMARC, dan dukungan Smarthost (Amazon SES, Mailgun, Brevo, SendGrid) per server maupun per domain.

Observabilitas & Migrasi

Log terpusat lintas layanan (Loki/Syslog), monitoring uptime & SSL, kesehatan SMART/inode/PSI, project quota per user, serta impor dari HestiaCP, cPanel, & VestaCP.

Instalasi Cepat (Standard Preset)

Atau gunakan Simulator Installer untuk memilih paket secara kustom.

Buka Simulator 
curl -fsSL https://raw.githubusercontent.com/StakoCP/stako/main/installer/install.sh | sudo bash -s -- --preset standard
